# Accepted secret-scanner findings. One line per finding group:
#
#     <repo-relative path> <rule-id> <count>
#
# Checked by scripts/run-gitleaks.sh, which fails in BOTH directions: a finding no line
# declares, and a line no finding matches. The count is pinned so this file cannot quietly
# grow -- a second finding of the same rule in the same file is a refusal, and a fix that
# removes a finding leaves a stale line that fails loudly instead of silently covering
# whatever appears there next. (The count is exact for the tree scan; in a history scan a
# finding recurs once per commit that touches its file, so the line is a membership test
# there. scripts/run-gitleaks.sh says so where it applies the difference.)
#
# This file is public. It records WHY a shape is accepted, never a value. A finding with
# no defensible reason is fixed, not listed here.
#
# Reproduce the list this file describes:
#
#     scripts/run-gitleaks.sh tree
